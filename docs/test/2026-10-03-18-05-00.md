# 2026-10-03 18:05: TDS2024 HARDCopy STARt (BMP over RS-232 via the TCP bridge)

Follow-up to `2026-10-03-17-45-00.md`. The user allowed `HARDCopy STARt`. Checks that the scope's screen dump arrives whole through the serial-to-Ethernet bridge, for the Stream Monitor's unverified TDS2024 case.

## Settings before the run (read-only queries, `--writebytedelayms 50`)

| Sent | Reply |
|---|---|
| `HARDCopy?` | `BMP;RS232;PORTRAIT;ON` |
| `HARDCopy:FORMat?` | `BMP` |
| `HARDCopy:PORT?` | `RS232` |
| `HARDCopy:LAYout?` | `PORTRAIT` |
| `RS232?` | `19200;0;0;NONE;CR` |
| `ALLEv?` | `0,"No events to report - queue empty"` |

## Command

```bash
(sleep 2; echo "HARDCopy STARt"; sleep 75) | dotnet run --project src/DevTerm.Console --no-build -- --transport tcp --host 192.168.0.110 --port 23 --presenter hex --parser ascii --lineending Lf --writebytedelayms 50 --cli true
```

The hex presenter prints each chunk as one `[hex]` line; the lines were joined and decoded offline.

## Result

- 77,878 bytes received, starting `42 4D` (`BM`). The BMP header's file-size field is 77,878, so nothing was lost or added.
- DIB header 40 bytes: 320 x 240, 1 plane, 8 bits per pixel, uncompressed, 76,800 bytes of pixels, 1,078-byte pixel offset (14 + 40 + 1,024 palette).
- Pillow opened it as a 320x240 palette image. The picture is the scope screen: the DG1022's XY plot (a tilted ellipse) with the DISPLAY menu (Type Vectors, Persist Off, Format XY) and `CH1 10.0V`, `CH2 10.0V`, `XY Mode` at the bottom.
- Nothing arrived after the image; the error queue was not read afterwards.

## Findings

- The hard copy streams through the bridge intact at 19200 baud with the 50 ms write delay set. The delay only affects what is written, so the 77 KB reply was unaffected.
- The earlier hexadecimal dump of a 78 KB capture is large for a terminal; the Stream Monitor is the right place to view one.
- Not tested: dev-term's Stream Monitor itself (its structural BMP end-finder and viewer) against this device. Only the raw capture was verified.

## Summary

No code change. Confirms the TDS2024 `HARDCopy STARt` output is a well-formed 320x240 8-bit BMP (the Stream Monitor case); the Stream Monitor run against it remains to be done.
