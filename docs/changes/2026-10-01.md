# 2026-10-01

## Real-hardware test pass: Zoom H4n remote (first confirmation)

`DevTerm.Devices.ZoomH4n` (implemented 2026-09-25) had never been run against a real unit —
`devterm.runsettings`' `RealSerialZoomH4nPort` held an unconfirmed COM3 guess. The `h4n2rs485`
adapter is now attached (enumerated as COM5), so `devterm.runsettings` was updated and
`RealHardwareZoomH4nTests.InvokeAsync_AgainstRealDevice_CompletesHandshakeAndSendsAButtonCommand`
run against it: passed — the init handshake completes and a `mic` button command sends without
fault or timeout. Full transcript: `docs/test/2026-10-01-08-15-06.md`.

Per this repo's own documented rule (`docs/design/README.md`'s Features section: a proposal moves
out of `proposals/` once completed *and* verified, not merely completed), moved
`docs/design/proposals/zoom-h4n-remote-protocol.md` to `docs/design/features/` and updated its
Status section, the README.md proposals/features lists, and every doc-comment cross-reference to
the old path (`RealHardwareZoomH4nTests`, `ZoomH4nControlSurfaceTests`, `ZoomH4nUiDefinition`,
`ZoomH4nDecoder`, `ZoomH4nControlSurface`, `DevicePanels`, `ui-definitions.md`).
