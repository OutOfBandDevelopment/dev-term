# 2026-10-14

## Listing live sessions

`--listsessions true` prints the sessions publishing on a `--pipe` (`SessionPipeServer.LiveSessions` enumerates `\.\pipe\devterm-session-*`; Windows only, empty elsewhere). A second process asking for a name already in use now gets `name-2`, `name-3`, ... (`AvailableName`) instead of failing to bind; applied in the CLI, TUI and WPF. Covered by `SessionPipeServerTests.LiveSessions_*` and `AvailableName_*`. `--pipe true` now names the pipe after the matching saved profile, else the transport (`Resolve`); the CLI prints the final attach name.

## `--capture <dir>` in the CLI

`CliOptions.Capture`: the CLI attaches a `StreamMonitor` to its session, saves detected streams into the folder and prints each `Captured ... to ...` line. Covered by `CliModeCaptureTests`. TUI and WPF keep their monitor windows.

## Manifest commands declare `ExpectedResponseFormat`

`OutboundCommand.ExpectedResponseFormat` (default `Text`, written by name) lets a device manifest command say its reply is an image, HP-GL, etc. `ManifestControlSurface.InvokeAsync` calls `ExpectResponse` on the session's `IStreamContentHintSink` presenters just before sending, same as `ScpiControlSurface`; nothing happens when no Stream Monitor is running. `schemas/device-manifest.schema.json` regenerated. Covered by `ManifestControlSurfaceTests.InvokeAsync_CommandDeclaringAResponseFormat_*` and `ExpectedResponseFormat_IsWrittenByName_AndReadBack`.

## Indicator `Format` and `Unit`

`IndicatorControl.Format` (.NET numeric format; `X2` shows the value as hex) and `Unit` shape the displayed text through `IndicatorControl.Display`; text with no number, or an invalid format, is shown as published. The TUI, WPF and web panels call it for directly published values, and `IndicatorState.Text` applies it to an expression's result, so charts and thresholds still see the raw number. Covered by `IndicatorStateTests.Display_*` and `Text_AppliesTheIndicatorsFormatAndUnit`; `ui-definition` and `device-manifest` schemas regenerated.
