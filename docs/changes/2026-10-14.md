# 2026-10-14

## Listing live sessions

`--listsessions true` prints the sessions publishing on a `--pipe` (`SessionPipeServer.LiveSessions` enumerates `\.\pipe\devterm-session-*`; Windows only, empty elsewhere). A second process asking for a name already in use now gets `name-2`, `name-3`, ... (`AvailableName`) instead of failing to bind; applied in the CLI, TUI and WPF. Covered by `SessionPipeServerTests.LiveSessions_*` and `AvailableName_*`. Defaulting the name to the profile name is still open.
