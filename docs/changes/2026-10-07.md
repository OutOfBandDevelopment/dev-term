## Named profiles

`--profile <name>` (`CliOptions.Profile`) now starts a run from a saved connection profile: `DevTermConfiguration.AddNamedProfile` layers it above `appsettings.Local.json` and below the project layer, environment variables and flags. The console app exits with "No saved connection profile named ..." for an unknown or invalid name. Test: `ProjectFileTests.ProfileFlag_LayersTheNamedSavedProfile_UnderCommandLineFlags_AndIgnoresAnUnknownOne`. Docs: connection-profiles design, managing-profiles guide.

## TCP share proxy

`--sharetcp <port> [--sharebind <ip>]` (CLI mode) shares the live session on a TCP port: `SessionTcpShareServer` is a session observer that copies device bytes to the one connected client and writes the client's bytes to the device via `Session.SendAsync`; a second client is closed at once; loopback by default. This is the proxy half of the RFC 2217 server decision; RFC 2217 negotiation is not built. Tests: `SessionTcpShareServerTests` (real loopback socket), `CliOptionsValidatorTests.ShareTcp_*`. Checked end to end with `--transport loopback` and a raw TCP client. Not in the TUI/WPF yet.
